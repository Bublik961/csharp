# Анонс центра 
## Назначение
Посетитель должен понять, что перед ним реклама курсов по новому языку C# и платформе .NET/
## Содержание
Заголовок: «Новый язык. Новая платформа. Новое будущее.»
Подзаголовок: «Курсы C# и .NET.»
Кнопка: «Записаться на курс». Рядом анимация загрузочного экрана Windows XP.
## Связь с объектом
Заголовок раскрывает факт выхода нового языка и платформы.
## Связь с эпохой
Формулировка заголовка в техно-оптимистичном стиле маркетинг 2000-х. Обещание «будущего» через новые технологии. Загрузочный экран Windows XP - доминирующая ОС эпохи.
## Визуальные ориентиры
Синяя шапка с рамкой, сине-зелено-фиолетовая палитра загрузочного экрана Windows XP.
