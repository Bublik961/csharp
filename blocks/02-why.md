# Почему C#
## Назначение
Объяснение посетителю ценности языка, причины по которым не стоит оставаться на  C++/VB6 или переходить на Java.
## Содержание
Основной текст: «Поддержка Microsoft. Знакомый синтаксис для С++ и Java- программистов. Автоматическая уборка памяти – меньше ошибок и падений программ. Единая платформа .NET вместо разрозненных инструментов».

## Связь с объектом
Синтаксис C# был сознательно сделан похожим на для С++ и Java, чтобы облегчить переход разработчиков.
## Связь с эпохой
Выбор разработчиков  между Java и продуктами Microsoft
## Визуальные ориентиры
Плотный текстовый блок, рамка, синие цвета.
## Ограничения
Не упоминать возможности языка появившееся после C# 2.0 (2005).
