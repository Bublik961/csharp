# Ключевая эпоха
## Временной диапазон
2002 – 2006 годы.
## Почему выбран этот период 
Официальный релиз C# в 2002 году вместе с .NET Framework 1.0 и Visual Studia .NET
2000-2003 - Спецификация C# была передана в Ecma International еще в 2000 году; первая редакция стандарта ECMA-334 была принята в декабре 2001 года, а стандарт ISO/IEC 23270 опубликован в 2003 году.
Ноябрь 2005 - выход C# 2.0, значимое расширение возможностей языка, сделавших его удобным для разработки крупных программ.
## Технологическая среда
Экраны: ЭЛТ-мониторы, первые ЖК-мониторы
Устройства: Настольные ПК, первые КПК
Носители: CD-ROM, CD-R/RW, 3.5-дюймовые дискеты
Операционные системы: Windows XP, Windows 2000
Типичные программы: Internet Explorer 6, ICQ, MSN Messenger, FlashGet, Visual Studio .NET
Способы подключения к сети: Dial-Up, ADSL и ISDN, LAN
## Визуальный язык
Плотное расположение текста, списков и таблиц, прямоугольные блоки, синие, темно-синие, серые, неоновые цвета. Шрифты: Tahoma, Times New Roman, Verdana, Arial. Кнопки прямоугольные с рамкой. Ссылки с подчеркиванием.
## Рекламный язык
Рекламный текст должен звучать уверенно и технологично. Формулировки: «Новая платформа разработки», «Ваш путь в мир .NET», 
Характерные обещания: «Гарантия трудоустройства и роста зарплаты в 2 раза», «Получение международных сертификатов Microsoft»
## Культурный фон
Журналы: MSDN Magazine, CoDe Magazine
## Границы стилизации
Минимализм, темная тема, скругления, изображения смартфонов, нейросетей, много пустого пространства.
