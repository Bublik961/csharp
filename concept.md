# Концепция
## Название вымышленных курсов
Курс «C# - язык нового тысячелетия»
## Идея одним предложением
Учебный центр гарантирует Windows-разработчикам на C++, VB 6 или Java быстрый переход на C# с сертификатом Microsoft.
## Кто предлагает обучение
Вымышленный учебный центр, производящий подготовку к сертификации Microsoft (MCSD/MCAD)
## Аудитория
Разработчики на C++ и VB6, рассматривающие продвижение по карьере.
## Главное обещание
«Освойте язык новой платформы .NET за 3 месяца и получите международный сертификат Microsoft».
## Голос рекламы
Уверенный, с присутствием терминологии эпохи: «платформа будущего», «управляемый код», «международный стандарт».
## Что посетитель должен понять об объекте
C# был создан Microsoft как язык новой управляемой платформы .NET, отвечающей на рост Java.
Низкий порог вхождения. Синтаксис C# имеет много схожего с другими языками программирования, благодаря чему облегчает переход для программистов. 
## Что агент не должен потерять при сборке
Не указывать месяц выхода C# 1.0.  – только год.
Сохранить формулировку «международный формат» как рекламную гиперболу, а не достоверный факт.
