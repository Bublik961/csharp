# Исследование C#
## Коротко
C# - объектно-ориентированный язык программирования общего назначения, созданный компаний Microsoft как основой язык для программной платформы .NET. Исторически интересен тем, что появился как часть маркетинговой стратегии Microsoft в ответ на распространение Java.
## Происхождение
История C# начинается в конце 1990-х годов, когда Microsoft осознала растущее доминирование Java. Лозунг Java «напиши один раз, запускай где угодно» привлекало корпоративных разработчиков, и Microsoft хотела иметь собственный мощный язык, тесно интегрированный с Windows.
Андерс Хейлсберг, идейный вдохновитель Turbo Pascal и Delphi, присоединился к Microsoft в 1996 году.
В 1999 году он начал работу над новым языком, первоначально называвшимся Cool («C-like Object Oriented Language»).
К 2000 году Microsoft представила .NET Framework вместе с C#, позиционируя его как современный, типобезопасный, объектно-ориентированный язык, предназначенный для повышения производительности.
## Исходная проблема
К 2000 году Microsoft доминировала на рынке персональных компьютеров (Windows), но её разработческая экосистема находилась в состоянии фрагментации:
•	COM (Component Object Model) - технология двоичного взаимодействия компонентов, требовавшая сложной регистрации, строгого соблюдения соглашений о вызовах, ручного подсчёта ссылок (AddRef/Release) и подверженная "DLL hell" (конфликтам версий библиотек);
•	MFC (Microsoft Foundation Classes) и ATL (Active Template Library) - фреймворки для C++, упрощавшие, но не устранявшие фундаментальные сложности языка;
•	visual-basic 6 - популярный язык для быстрой разработки GUI-приложений, но ограниченный по выразительности, лишённый современных возможностей (наследование, обобщения), и не предназначенный для масштабных систем;
•	ASP (Active Server Pages) - серверная технология для динамических веб-страниц, использовавшая скрипты на VBScript или JScript, без строгой типизации и с низкой производительностью;
•	Отсутствовала единая модель развертывания, отладки, безопасности и межъязыкового взаимодействия.
Кроме того, на горизонте появилась Java - платформа, основанная на концепции виртуальной машины (JVM), автоматическом управлении памятью (сборщик мусора), строгой типизации и "write once, run anywhere". Её успех продемонстрировал рыночный спрос на безопасную, переносимую и продуктивную среду разработки.
Microsoft осознала необходимость создания собственной унифицированной платформы, которая:

•	сохранила бы преимущества Windows (доступ к нативным API, высокая производительность, интеграция с ОС);
•	устранила бы фрагментацию разработческих моделей;
•	обеспечила бы безопасность и стабильность по умолчанию;
•	поддерживала бы несколько языков программирования на равных правах;
•	позволяла бы развёртывание без конфликтов версий.
Так возник проект NGWS (Next Generation Windows Services), позже переименованный в .NET. C# был её флагманским языком. Ключевые цели языка включали:
•	Бесшовную интеграцию с Common Language Runtime (CLR) .
•	Синтаксис, знакомый разработчикам на C++ и Java .
•	Быструю разработку приложений для Windows.
## Пользователи и области применения
Пользователи: разработчики корпоративного ПО под Windows, ранее писавшие на C++ или Visual Basic 6; 
Области применения: настольные бизнес-приложения (Widows Forms), веб-разработка (ASP.NET), работа с базами данных (ADO.NET).
## Ключевые вехи
1999 – начало разработки языка под именем Cool.
2002 – выход C# 1.0 вместе с релизом Visual Studio .NET 2002 и платформой .NET Framework. Первая версия C# содержала: классы, структуры, интерфейсы, делегаты, операторы и выражения, атрибуты.
2003 - в составе Visual Studio .NET 2003 вышла версия C# 1.1, а за ней и C# 1.2. Они содержали небольшое количество мелких изменений языка. 
2005 - вместе с Visual Studio 2005 вышел C# версии 2.0. Появились обобщённые типы (generics), разделенные типы (partial), анонимные функции, nullable-типы, итераторы и оператор yield return.
## Важные платформы, продукты и проекты
.NET Framework – платформа, вместе с которой вышел C#.
Visual Studio .NET 2002 / 2003/ 2005 – основная среда разработки.
## Почему объект был ценен в выбранную эпоху
Язык вышел вместе с новой платформой .NET. Это была первая попытка Microsoft дать разработчикам современный инструмент вместо разрозненных MFC, COM, VB6.
Язык был построен так, чтобы был знаком C++ и Java-программистам. Переход давался легче.
## Факты для рекламной концепции
Соперничество с Java как фон появления языка.
Первоначальное кодовое название - COOL.
